# 进入服务器

游戏内使用离线账号，真实身份由皮肤站里的绑定决定，进服不需要另设密码。

服务器地址从两个地方来：

- 启动器的服务器列表
- 管理员发来的地址，填进「添加服务器」

## 谁能进

| 服务器 | 谁可以进 |
| --- | --- |
| 同好会服务器 | 吉林大学在校成员 |
| 联盟互通服务器 | 吉林省 MC 高校联盟成员高校的玩家 |
| 省外服务器 | 按全国 MUA 规范互通的服务器 |

## 进不去

确认启动器已登录，确认地址是最新那条。换另一台联邦服务器的地址，它们在不同网络里。
