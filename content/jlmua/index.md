# 吉林省 MC 高校联盟

JLMUA 是吉林省内高校 Minecraft 社团组成的省级联盟，同好会是成员之一。
各校社团各自开服，玩家用同一套账号在这些服务器之间互通。

## 三级互通

```
吉林大学 Minecraft 同好会（JLUCraft）
        │  同一套账号与材质
吉林省 MC 高校联盟（JLMUA）  ← 成员高校的社团
        │  全国 MUA 规范
全国 MC 高校联盟（MUA）
```

- **同好会内**：成员服、活动服、比赛服
- **省联盟内**：成员高校的服务器之间身份互认，材质一致
- **出省**：按全国 MUA 规范，在对方站点登录同一套身份

## 共用什么

| 能力 | 做法 |
| --- | --- |
| 账号 | 各校用学校邮箱注册，同一个皮肤站，账号跨校通用 |
| 材质 | 皮肤站统一签名，所有服务器从同一地址取 |
| 身份 | 身份日志记录角色归属，跨校准入按同一套规则 |
| 赛事 | 联盟内按赛季组织，比赛服装计分插件上报 |

基础设施由吉林大学同好会维护：皮肤站、联邦服务器、启动器与管理端都是同好会的项目。

## 加入联盟

吉林省内高校的 Minecraft 社团接入同一套皮肤站与联邦服务器，
社团成员用各自的学校邮箱注册后即可互通。具体接口与规范见 [MUA 开发文档](https://docs.mualliance.cn/dev/union)。
