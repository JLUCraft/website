# 隐私声明

更新日期：2026-10-22

## 适用范围

皮肤站账号体系、本站页面、启动器与管理端的登录。

## 收集的信息

| 信息 | 用途 |
| --- | --- |
| 学校邮箱 | 验证邮箱归属，决定社团归属 |
| 角色名 | 游戏内身份 |
| 密码 | 以 scrypt 哈希存储，明文不入库 |
| 皮肤与披风图片 | 材质与皮肤库 |
| 通行密钥公钥 | Passkey 登录 |
| 设备公钥 | 身份日志里的设备绑定 |
| 进服记录：服务器、角色、IP、过期时间 | 排障与限流，过期后清理 |
| 验证码 | 邮箱验证与重置密码，15 分钟内有效 |

## 存储位置

- 皮肤站数据库，部署在社团自己的服务器上
- 材质文件存储，按内容哈希命名
- 身份日志：追加式记录，写入角色归属与吊销，联盟内各校服务器共同读取

## 信息共享范围

| 对象 | 获取内容 |
| --- | --- |
| 联盟内服务器 | 角色身份、材质 |
| 全国 MUA 成员站 | 按规范同步的角色名、UUID、材质与邮箱归属查询结果 |
| 其他玩家 | 公开到皮肤库的材质与角色名 |

站点不接入第三方统计与广告。

## Cookie

Passkey 登录用一次性 cookie 关联挑战与账号，哈希后存库，过期即删。

## 保留期限

| 数据 | 保留 |
| --- | --- |
| 验证码、一次性挑战 | 到期删除 |
| 登录令牌 | 到期失效，重置密码后全部失效 |
| 进服记录 | 过期清理 |
| 身份日志 | 长期保留：追加式记录，用于校验历史绑定与吊销 |

## 删除账号

在 QQ 群 361033103 联系管理员。删除后邮箱、角色、材质从皮肤站移除；
身份日志里的历史绑定与吊销记录保留，联盟内服务器据此拒绝旧身份。

## 变更

页面更新即生效，日期写在页首。
