# JLUCraft { .lp-title }

用学校邮箱注册一次，就能登录全省共用的皮肤站、进入各校的联邦服务器，并与全国 MUA 互通。 { .lp-lead }

::: lp card
### 一个皮肤站
全省共用一套账号与材质，换学校不用重新注册。
:::

::: lp card
### 多台联邦服务器
各校自建服务器组成联邦，玩家之间互相可见、可联机。
:::

::: lp card
### 与 MUA 互通
按全国 MUA 规范接入，跨省也能认得出你。
:::
::::

::: lp steps
## 三步开始 { .lp-section-title }

1. **用学校邮箱注册账号** —— 在[皮肤站](https://skin.jlucraft.com/portal/)填写学校邮箱，收信验证后即可创建角色。
2. **用启动器登录** —— 启动器内置本联合体的认证服务器，登录即完成身份绑定。
3. **连接服务器进入游戏** —— 从启动器获取服务器地址，或由同学发来连接链接。
:::
