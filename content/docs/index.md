# 玩家文档

## 准备

- 能运行 Minecraft Java 版的电脑
- 学校邮箱（吉林大学邮箱，或联盟内其它高校的邮箱）
- 同好会的启动器：[下载页](https://github.com/JLUCraft/FollyLauncher/releases)

游戏内使用离线账号，身份来自皮肤站里学校邮箱绑定的角色。

## 三步

1. [注册账号](/docs/register)
2. [安装并登录启动器](/docs/launcher)
3. [进入服务器](/docs/server)
