# 安装与登录启动器

## 下载

从[发布页](https://github.com/JLUCraft/FollyLauncher/releases)下载对应系统的安装包。
Windows、macOS、Linux 都有构建产物。

## 登录

启动器内置同好会的认证服务器，选择它登录。出现授权提示时，在浏览器里完成，再回到启动器。

登录成功后启动器刷新材质与服务器列表。

## 启动游戏

启动器管理游戏实例与 Java 运行时。新建实例后，每次登录直接启动。
