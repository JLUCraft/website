# 进入服务器

游戏内使用离线账号，真实身份由皮肤站里的绑定决定，进服不需要另设密码。

服务器地址从两个地方来：

- 启动器的服务器列表
- 管理员发来的地址，填进「添加服务器」

## 准入范围

| 服务器 | 准入对象 |
| --- | --- |
| 同好会服务器 | 吉林大学在校成员 |
| 联盟互通服务器 | 吉林省 MC 高校联盟成员高校的玩家 |
| 省外服务器 | 按全国 MUA 规范互通的服务器 |

## 连接排查

连接失败时，先在启动器确认登录状态，刷新列表核对服务器地址；主入口连不上时切换备用节点，详细排查见[常见问题](/docs/faq)。
