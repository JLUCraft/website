# 网络与中继

## 玩家侧

1. 启动器在本地起一个回环代理，游戏客户端连的是 `127.0.0.1`。
2. 启动器用设备身份与服务端握手，把流量放进加密隧道。
3. 联邦服务器在中继角色下把流量转给本机游戏服务端，并用 modern forwarding 传递身份与材质。玩家侧无需暴露公网端口，在校园网、家庭宽带或 NAT 后均使用同一连接流程。

## 发现

- **目录服务**：客户端向已知节点请求目录，拿到当前可用的服务记录。
- **局域网发现**：同一网段内通过 mDNS 找到服务器，适合活动当天的临时联机。
- **多入口**：一台节点可以配置 `bootstrap` 与 `reserve`，某个入口不可达时换下一个。

## 与外省互通

出省流量按全国 MUA 规范处理：成员站之间用资料与材质接口同步，
游戏内的跨站对局依赖对方站点的能力。联盟不额外维护一层自建大厅。

## MUA 联合大厅兼容策略

系统不内置 MUA 联合大厅的 frp 接入协议：大厅入口依赖未公开规范的 BungeeCord 兼容转发与插件侧信任机制。省联盟内通过联邦网络实现 NAT 穿透与多入口；需要接入全国联合大厅的成员校单独运行官方旁路进程，与本系统的 Velocity 转发后端隔离。
