# 服务器与服务

| 服务 | 用途 | 进入方式 |
| --- | --- | --- |
| 成员服 | 日常联机、建筑与生存 | 启动器服务器列表 |
| 活动服 | 活动与小游戏的临时世界 | 活动期间公布地址 |
| 比赛服 | 联赛对局，装 UnionScoring 计分插件 | 赛事期间公布地址 |
| 成员房间 | 几人临时开一局 | 启动器里创建或加入房间 |
| 联盟互通 | 与吉林省内其它高校的玩家一起玩 | 地址来自对方社团 |

地址都在启动器的服务器列表里，或由管理员直接发给你。

## 玩法

- 生存与建筑是主线，成员服长期开放
- 活动服按活动主题开，结束后存档保留
- 比赛按赛季组织，报名与对阵在[管理端](/tech/clients)与启动器里看
