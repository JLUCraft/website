# 办公与审批

办公与审批由皮肤站统一承载，管理面由 agent + MCP 提供。

## 流程形态

1. **草稿**：发起人填写内容，可以反复修改
2. **审批**：按流程要求由指定角色审阅，可附意见与要求修改
3. **联署**：需要多方签署时逐一收集签名
4. **发布**：满足条件后固化，写入记录，对外可见

## 状态与签名

每一步都记录操作者、时间与签名；状态机不接受「跳过」，
被拒绝的版本不能原样重提，需要修改后生成新版本。

## 权限来源

审批与签发权限直接读取皮肤站里的社团成员与角色授权，随人员任免更新，不在配置文件中静态声明。

## 接口

流程定义与状态机由皮肤站的审批模块提供，管理面通过 MCP 调用。
